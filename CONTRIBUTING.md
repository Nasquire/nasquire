# 기여 정책 / Contribution policy

## 한국어

버그 보고와 기능 제안은 [이슈](https://github.com/Nasquire/nasquire/issues/new/choose)로 환영합니다. 재현 절차와 기대 동작을 설명하고 비밀값·개인정보는 제거하세요.

향후 라이선스 선택의 유연성을 유지하기 위해 외부 코드 기여를 받지 않으며 반영하지 않습니다. PR·패치뿐 아니라 이슈에 첨부된 코드·문서·번역도 포함합니다. 구현물을 보내지 말고 문제와 원하는 동작을 설명해 주세요. 제안은 아이디어로만 참고하고 메인테이너가 직접 구현합니다. 외부 PR은 안내 후 닫습니다.

보안 취약점은 공개 이슈에 올리지 마세요. 저장소 **Security → Advisories → Report a vulnerability**에서 [비공개 보고](https://github.com/Nasquire/nasquire/security/advisories/new)를 제출하세요. 지원 버전과 공개 전 조율은 [보안 정책](SECURITY.md)을 참고하세요.

## English

Bug reports and feature requests are welcome through [issues](https://github.com/Nasquire/nasquire/issues/new/choose). Describe reproduction steps and expected behavior; remove secrets and personal information.

To preserve flexibility in future licensing choices, external code contributions are neither accepted nor incorporated. This includes PRs, patches, and code, documentation or translations attached to issues. Describe the problem and desired behavior rather than submitting implementations. Suggestions are considered as ideas only; the maintainer implements changes independently. External PRs are closed with an explanation.

Do not report vulnerabilities in public issues. Open **Security → Advisories → Report a vulnerability** in this repository to [report privately](https://github.com/Nasquire/nasquire/security/advisories/new). See the [security policy](SECURITY.md) for supported versions and disclosure coordination.
