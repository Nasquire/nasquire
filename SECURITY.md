# 보안 정책 / Security policy

## 한국어

보안 수정 지원 대상은 **최신 릴리스**입니다. 이전 버전 사용자는 최신 릴리스로 업그레이드하세요.

취약점은 공개 이슈·PR 대신 저장소 **Security → Advisories → Report a vulnerability**에서 [GitHub 비공개 취약점 보고](https://github.com/Nasquire/nasquire/security/advisories/new)를 이용하세요. 영향받는 버전·lite/full 빌드·설치 방식·재현 절차·예상 영향을 설명하고 비밀값·개인정보·실제 문서 원문은 제거하세요. 수정 코드·패치는 받지 않습니다([기여 정책](CONTRIBUTING.md)).

메인테이너와 비공개로 영향·수정·권고문 공개 시점을 조율하고, 조율 전에는 취약점 세부 사항을 공개하지 마세요. 응답·수정 기한은 보장하지 않습니다.

## English

Security fixes are supported for the **latest release**. Upgrade older versions to the latest release.

Use **Security → Advisories → Report a vulnerability** to [report privately through GitHub](https://github.com/Nasquire/nasquire/security/advisories/new), rather than opening a public issue or PR. Include the affected version, lite/full build, installation method, reproduction steps and expected impact. Remove secrets, personal information and original private documents. Fix code and patches are not accepted ([contribution policy](CONTRIBUTING.md)).

Coordinate impact, remediation and advisory publication privately with the maintainer before disclosing vulnerability details. Response and remediation deadlines are not guaranteed.
